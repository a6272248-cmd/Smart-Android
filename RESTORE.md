# Restore instructions

1. Extract this archive into a new directory.
2. Create a branch: `git switch -c codex/development-audit`.
3. Review `DEVELOPMENT_CHANGELOG.md` and `README-AR.md`.
4. With a JDK, Android SDK, and Gradle available, run the workflow or `gradle assembleDebug`.
5. Do not merge into `main` until review is complete.

This archive is a source snapshot. It does not contain a built APK or signing keys.
