# Smart-Android — حزمة المصدر الموحدة للرفع إلى GitHub

هذه نسخة مصدر **تطويرية قابلة لتجربة البناء**، ليست APK نهائيًا ولا تطبيقًا مكتمل الوظائف. ارفع **محتويات** هذا المجلد مباشرة إلى جذر مستودع `Smart-Android`، لا المجلد الخارجي نفسه.

## الحصول على APK تجريبي

من GitHub > Actions > Android APK build > Run workflow، وبعد نجاح التشغيل نزّل `SmartManager-Android-debug-APK` من Artifacts. ملف debug موقّع تلقائيًا بمفتاح اختبار، وهو غير مناسب لنشر تحديثات إنتاجية دائمة. لم يُجرَ بناء APK داخل هذه البيئة؛ ينبغي التأكد من نجاح GitHub Actions.

## الحالة التقنية

- Java، Native API مباشرة إلى الراوتر، المنفذ 8728 افتراضيًا غير مشفر؛ TLS اختياري مع تحقق الشهادة.
- قراءة الموارد، Hotspot، PPPoE، بعض بيانات User Manager v6/v7، إنشاء مستخدم Hotspot ودفعات حتى 50، تصدير PDF.
- وظائف User Manager الكاملة وإنشاء دفعاته وصيانته لم تكتمل. الترقيم محلي لكل جهاز وغير متزامن بين الهواتف.
- لم تُختبر اتصالات RouterOS الحقيقية ولا صلاحيات التعديل ولا الواجهة على هاتف أندرويد حقيقي.
- تجنّب استخدام حساب الراوتر الرئيسي؛ خصص مستخدم API بصلاحيات مقيدة ولا تعرض الخدمة خارج LAN.

## فحوصات CI

يتحقق مسار Actions أولًا من ترميز البروتوكول وتجربة خادم وهمي، ثم يحاول بناء `assembleDebug`، ويحتفظ بملف APK في Artifacts عند النجاح.

## هيكل الملفات

`app/` كود التطبيق، `tests/` اختبارات بروتوكول، `.github/workflows/` بناء APK، وملفات Gradle في الجذر.

# Smart Manager Android — v0.4 Preview

## الحالة
مشروع Android أصلي بدون OpenWrt أو PHP؛ **ليس APK مبنيًا أو نسخة نهائية مضمونة**. لا ترفع كلمات مرور الراوتر أو مفاتيح توقيع إلى GitHub. ملف GitHub Actions مهيأ لمحاولة بناء APK تجريبي عند رفع المشروع، لكن لم يُشغّل هنا.

## الميزات المتوفرة في المصدر
اتصال مباشر RouterOS Native API (8728 افتراضي غير مشفر، أو TLS مع التحقق من شهادة الجهاز حسب اختيار المستخدم)؛ قراءة الموارد، Hotspot، PPPoE، User Manager بإصدارين، الباقات والجلسات. إنشاء مستخدم Hotspot منفرد ودفعات حتى 50، معاينة وتصدير PDF. حفظ اسم الراوتر والمنفذ واسم المستخدم وخيار TLS **دون حفظ كلمة المرور**.

## قيود مهمة
- عمليات User Manager الخاصة بإنشاء دفعات وبناء الباقات والصيانة والنسخ الاحتياطي لم تُنجز؛ لا تنفذ هذه الأوامر على راوتر فعلي بعد.
- الترقيم المحلي لا يمنع التصادم من عدة هواتف؛ أُوقف إنشاء الدفعة عند مصادفة اسم موجود بدل تخطيه وإخفاء عدد البطاقات المنشأة.
- من الممكن إنشاء مستخدم قبل انقطاع الاتصال وعدم وصول تأكيد؛ راجع الراوتر قبل إعادة المحاولة.
- لا توجد اختبارات أجهزة حقيقية RouterOS v6/v7 أو Android، ولا Android SDK متاح لإنتاج APK داخل البيئة الحالية.

## بناء APK
افتح الجذر في Android Studio، استخدم JDK 17 وSDK 35، ثم Build > Build APK. أو ارفع كامل محتويات المجلد إلى مستودع GitHub الخاص وشغّل Actions / Android APK build. البناء الآلي ينتج **debug APK** موقّعًا تلقائيًا بمفتاح debug مؤقت؛ التوزيع النهائي يحتاج مفتاح release محفوظًا خارج GitHub.

## السلامة
المنفذ 8728 غير مشفر. استخدم حساب API محدود الصلاحيات ولا تعرّض API للإنترنت. التوقيع مجاني ولا يحتاج اشتراكًا. هذا المشروع لا يغيّر إعدادات الخدمة ولا يثبت أي شيء على راوتر MikroTik.
